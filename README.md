# 备忘录四象限

> 单文件、离线可用的浏览器备忘录 / 工作台。双击 HTML 即可打开——无需安装、无需联网、无后端、零依赖。

## 特性

- 📝 **备忘录**：富文本编辑、置顶（Pin）、分组、拖拽排序、点击展开 + 失焦自动收起
- 🎨 **多主题**：浅色 / 深色 / 液态玻璃（glass）/ 护眼（green），整页深浅色一致协调
- 🔃 **排序记忆**：排序字段与升降序会被记住，刷新不丢
- 📅 **日历**：内置农历、节气、节假日（内嵌 lunar 农历库，无网络依赖）
- 📊 **统计可视化**：备忘数据的统计视图
- 💾 **本地存储**：数据保存在浏览器 `localStorage`，不上传任何服务器
- 🖥️ **电脑端优先**：为桌面浏览器体验优化

## 使用

直接用浏览器打开 `备忘录四象限.html` 即可使用。所有内容只存在于本机浏览器，清除浏览器数据会一并清除。

## 部署

纯静态单文件，可整仓库一键托管到 GitHub Pages，或直接下载 HTML 本地使用。
